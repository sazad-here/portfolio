## Notes

- **Reliance Under Disruption** is a copy for showcasing. Its live study deploys from the original [reliance-under-disruption](https://github.com/sazad-here/reliance-under-disruption) repo, so development continues there.
- **Managerial Decision Making** data files are generated from the coursework workbooks (`managerial-decision-making/tools/build_portfolio_data.py` in the coursework repo).
- **Healthcare Analytics** is generated from the private coursework repo (`healthcare-analytics-ai/tools/build_site.py`). Rebuild it there instead of editing these files by hand.
- New course projects get their own folder here and a card on [index.html](index.html).
